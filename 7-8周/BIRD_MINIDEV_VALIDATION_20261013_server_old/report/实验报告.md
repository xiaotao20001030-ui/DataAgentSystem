# 小模型 Schema 鲁棒性与向量检索外键偏差

## BIRD Mini-Dev 验证性实验报告

日期：2026-10-23  
数据：BIRD Mini-Dev SQLite（500 题，11 个数据库）  
模型：Qwen3-0.6B / 1.7B / 4B、Qwen2.5-Coder-1.5B、DeepSeek deepseek-chat

## 摘要

本文在 BIRD Mini-Dev 的 500 个问题上，考察本地小模型与 API 大模型在 schema 扰动下的执行鲁棒性差异，并检验向量检索是否系统性漏掉多表问题中的连接成分。结果表明：

1. 向量检索对外键/连接列的漏选率显著高于普通目标列（+13.75pp，95% CI [+9.79, +17.73]）。
2. 加入 20 个真实无关列后，四个小模型相对大模型的执行准确率下降均未达到预注册的 10pp 门槛，效应接近零。
3. 在双方基线均可解的子集上，小模型的保持率显著更低（+16.5 到 +51.9pp）。

总体而言，「小模型总体上比大模型多下降 10pp」的操作化假设未获支持；但检索外键偏差与条件效应为后续研究提供了明确方向。

## 1 研究问题与假设

- RQ1：加入无关列后，小模型执行准确率是否比大模型下降更多？
- RQ2：向量检索是否更容易漏掉多表问题中的外键/连接列？

预注册门槛：

- H1（检索）：外键/连接列的漏选率显著高于普通目标列（配对 95% CI 下界大于 0）。
- H2（执行）：小模型在加入 20 个无关列时的执行准确率下降，比大模型至少多 10 个百分点。

## 2 实验设计

### 2.1 数据

BIRD Mini-Dev SQLite，500 个 question_id，11 个数据库。难度分布：simple 148、moderate 250、challenging 102。基线 schema 由 gold SQL 经 sqlglot 解析得到，仅保留 gold SQL 实际引用的表与列；500 条基线均通过 schema qualification。

### 2.2 模型

| 模型 | 角色 | 参数 |
| --- | --- | ---: |
| Qwen3-0.6B | 小模型 | 0.6B |
| Qwen3-1.7B | 小模型 | 1.7B |
| Qwen3-4B | 小模型 | 4B |
| Qwen2.5-Coder-1.5B-Instruct | 小模型 | 1.5B |
| DeepSeek deepseek-chat | 大模型对照 | — |

所有模型使用相同 prompt 与最大输出长度；小模型用贪心解码，大模型 temperature=0。

### 2.3 条件

| 条件 | 说明 | 题数 |
| --- | --- | ---: |
| base | 仅 gold 表与列 | 500 |
| 多给 20 列·任意表 | 加入 20 个全库范围内的真实无关列 | 431 |
| 多给 20 列·仅 gold 表 | 加入 20 个 gold 表内的真实无关列，不新增表 | 224 |
| 漏给·桥接表 | 从 schema 移除桥接表 | 103 |
| 漏给·外键列 | 从 schema 移除关键外键/连接列 | 494 |

多给条件只使用真实列，不使用合成列；候选不足 20 的题目直接排除并记录。漏给条件仅从 prompt 的 schema 移除表或列，物理数据库保持不变。

### 2.4 评分

预测 SQL 与 gold SQL 均在只读 SQLite 连接中执行，采用 BIRD 官方集合语义 `set(predicted_rows) == set(gold_rows)`，30 秒超时；执行错误按 incorrect 计。

### 2.5 向量检索

使用 sentence-transformers/all-MiniLM-L6-v2 对列做向量化，查询为 question-only，主分析 k=10。为控制题目类型混淆，引入「多表非桥接目标列」基线（多表题中既非桥接表列、也非连接列的目标列），并做问题级配对 bootstrap（10000 次）。

## 3 结果

### 3.1 检索（H1）

| 类别 | 漏选率 |
| --- | ---: |
| 单表目标列 | 28.71% |
| 多表非桥接目标列 | 47.45% |
| 桥接表内列 | 41.60% |
| 外键/连接列 | 57.85% |

配对差值（k=10）：

| 比较 | 差值 | 95% CI | 判定 |
| --- | ---: | --- | --- |
| 外键/连接列 − 多表非桥接目标列 | +13.75pp | [+9.79, +17.73] | 显著 |
| 桥接表内列 − 多表非桥接目标列 | −13.91pp | [−24.22, −3.69] | 不更难 |

H1 成立，但偏差集中在外键/连接列，而非桥接表本身。

### 3.2 执行准确率（H2）

| 模型 | base | 多给20列·任意表 | 多给20列·仅gold表 |
| --- | ---: | ---: | ---: |
| DeepSeek deepseek-chat | 68.6% | 67.1% | 56.7% |
| Qwen3-0.6B | 14.8% | 12.1% | 7.6% |
| Qwen3-1.7B | 27.6% | 23.7% | 15.6% |
| Qwen3-4B | 50.4% | 42.5% | 37.1% |
| Qwen2.5-Coder-1.5B | 26.4% | 20.9% | 18.3% |

小模型相对 DeepSeek 的额外下降：

| 模型 | 任意表（n=431） | 仅gold表（n=224） |
| --- | ---: | ---: |
| Qwen3-0.6B | +0.46pp | 0.00pp |
| Qwen3-1.7B | +2.09pp | +1.34pp |
| Qwen3-4B | +5.10pp | +0.89pp |
| Qwen2.5-Coder-1.5B | +3.25pp | −1.79pp |

四个小模型在两种条件下的额外下降均低于 10pp，绝大多数接近 0。H2 不成立。

### 3.3 条件效应（基线可解子集）

在双方基线均可解的题上，统计扰动后的保持率（任意表条件）：

| 模型 | 共同正确题数 | 额外失败 | 95% CI |
| --- | ---: | ---: | --- |
| Qwen3-0.6B | 60 | +28.33pp | [+16.67, +41.67] |
| Qwen3-1.7B | 114 | +29.82pp | [+21.05, +38.60] |
| Qwen3-4B | 200 | +16.50pp | [+11.00, +22.50] |
| Qwen2.5-Coder-1.5B | 104 | +37.50pp | [+26.92, +48.08] |

小模型对 schema 干扰的额外敏感集中体现在「原本会做」的题上；由于小模型基线准确率较低（地板效应），该效应没有转化为总体 10pp 的下降差。

### 3.4 漏给

| 模型 | 桥接·普通 | 桥接·合规 | 外键·普通 | 外键·合规 |
| --- | ---: | ---: | ---: | ---: |
| DeepSeek deepseek-chat | 19.42% | 11.11% | 35.02% | 2.47% |
| Qwen3-0.6B | 0.00% | 0.00% | 1.62% | 2.50% |
| Qwen3-1.7B | 2.91% | 11.11% | 7.49% | 3.82% |
| Qwen3-4B | 2.91% | 5.66% | 20.24% | 2.41% |
| Qwen2.5-Coder-1.5B | 1.94% | 9.09% | 10.12% | 1.26% |

「普通」为执行准确率；「合规」为预测 SQL 不使用被移除表/列的比例。移除连接成分后，所有模型的严格合规准确率都很低，大模型的普通执行优势主要来自读取或猜中被隐藏的连接列。

## 4 讨论

- 检索偏差集中在语义信息较弱的外键/连接列（`id`、`*_id`），与「连接键在向量空间中缺乏语义」的解释一致；桥接表名通常有辨识度，因此并不更难召回。
- 全体准确率门槛受地板效应影响：小模型基线准确率低，绝对下降空间有限，因此「相对大模型多下降 10pp」这一全体门槛较难满足。
- 条件分析显示，在基线可解的题上小模型保持率显著更低，说明小模型确实对 schema 干扰更敏感，只是这一效应被总体门槛的构造方式掩盖。
- 漏给结果支持「连接 schema 成分缺失会造成严重退化」，但不支持「大模型能在完全不使用缺失成分时稳定恢复」。

## 5 结论

- H1 成立：向量检索对外键/连接列存在稳健漏选偏差（+13.75pp）。
- H2 不成立：小模型加入 20 个真实无关列后，总体执行下降未比大模型多 10pp。
- 条件效应存在：在基线可解的题上，小模型保持率显著更低（+16.5 到 +51.9pp）。
- 下一步：在 Spider 2.0-Lite SQLite 上复验，以「基线可解子集上的保持率差」为主指标，并先做功效分析。

## 6 局限

| 维度 | 局限 |
| --- | --- |
| 推理方差 | 单次贪心解码，无多种子重跑；CI 只覆盖题目间方差 |
| 外部效度 | 单个 Mini-Dev 数据集、单个 MiniLM 检索器、单一 DeepSeek 快照 |
| 地板效应 | 小模型基线准确率低，总体下降空间受限 |
| API 可复现性 | DeepSeek 温度 0 仍存在约 0.4pp 的运行间波动 |
