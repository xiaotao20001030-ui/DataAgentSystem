# 7-8 周验证性实验：结论

*BIRD Mini-Dev SQLite，500 题，11 库；四个小模型 + DeepSeek；2026-10-23*

## 一句话

向量检索对外键/连接列存在稳健漏选偏差；但「小模型加 20 列后总体比大模型多下降 10pp」
的主门槛不通过，效应接近零。小模型对 schema 干扰的额外敏感集中在「基线可解」的题上。

## 两个假设的判定

| 假设 | 结论 |
| --- | --- |
| H1：向量检索更易漏掉外键/连接列 | **成立**（+13.75pp，95% CI [+9.79, +17.73]） |
| H2：小模型加 20 列后总体下降比大模型多 ≥10pp | **不成立**（四模型额外下降 0.00 到 +5.10pp） |

## 核心结果

### 检索（H1）

| 类别 | 漏选率 |
| --- | ---: |
| 多表非桥接目标列 | 47.45% |
| 桥接表内列 | 41.60% |
| 外键/连接列 | 57.85% |

外键/连接列显著更难（+13.75pp），桥接表本身不构成额外偏差（−13.91pp）。

### 执行（H2）

小模型相对 DeepSeek 的额外下降：

| 模型 | 多给20列·任意表 | 多给20列·仅gold表 |
| --- | ---: | ---: |
| Qwen3-0.6B | +0.46pp | 0.00pp |
| Qwen3-1.7B | +2.09pp | +1.34pp |
| Qwen3-4B | +5.10pp | +0.89pp |
| Qwen2.5-Coder-1.5B | +3.25pp | −1.79pp |

四模型均低于 10pp，H2 不成立。

### 条件效应

在双方基线都可解的题上，小模型保持率显著更低：

| 模型 | 额外失败 | 95% CI |
| --- | ---: | --- |
| Qwen3-0.6B | +28.33pp | [+16.67, +41.67] |
| Qwen3-1.7B | +29.82pp | [+21.05, +38.60] |
| Qwen3-4B | +16.50pp | [+11.00, +22.50] |
| Qwen2.5-Coder-1.5B | +37.50pp | [+26.92, +48.08] |

### 漏给

移除桥接表或外键列后，五模型严格合规准确率都很低（1.26%–11.11%）；DeepSeek 的普通执行优势
主要来自读取或猜中被隐藏的连接列。

## 结论与下一步

- 主门槛（总体 10pp）不通过，但检索外键偏差和条件效应稳定存在。
- 研究重心应转向「外键/连接列检索」与「基线可解子集上的条件鲁棒性」，而不是无关列数量。
- 下一步：Spider 2.0-Lite SQLite 复验，主指标改为基线可解子集上的保持率差，先做功效分析。
