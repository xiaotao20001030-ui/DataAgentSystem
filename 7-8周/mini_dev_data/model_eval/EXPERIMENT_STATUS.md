# BIRD Mini-Dev 验证性实验状态

## 已完成：向量检索偏差实验

- 数据：BIRD Mini-Dev SQLite 500 题、11 个数据库
- 标签：gold SQL 必需列、关键外键/连接列、桥接表
- 向量模型：`sentence-transformers/all-MiniLM-L6-v2`
- 主分析：`k=10`
- 不确定性：按问题聚类的 10,000 次 bootstrap

### 仅使用 question

| 指标 | 漏选数 | 总数 | 漏选率 |
| --- | ---: | ---: | ---: |
| 单表目标列 | 60 | 209 | 28.71% |
| 桥接表（表级，有任一列即命中） | 17 | 103 | 16.50% |
| 桥接表内列 | 104 | 250 | 41.60% |
| 外键/关键连接列 | 564 | 975 | 57.85% |
| 桥接成分并集 | 587 | 1032 | 56.88% |

| 与单表目标列比较 | 差值 | 95% CI | 单侧 p |
| --- | ---: | --- | ---: |
| 桥接表内列 | +12.89 pp | [+2.21, +23.45] pp | 0.0100 |
| 外键/关键连接列 | +29.14 pp | [+21.49, +36.84] pp | 0.0001 |
| 桥接成分并集 | +28.17 pp | [+20.58, +35.65] pp | 0.0001 |

桥接成分漏选率显著高于单表目标列，检索部分通过。

桥接表是表级口径，只要桥接表有一列进入 top-k 就算覆盖，其漏选率并不高于
单表目标列。科学上更直接的支持证据是桥接表内列和外键列，两者均显著更高。

### 使用 question + evidence

`k=10` 下，外键/关键连接列漏选率为 58.97%，单表目标列为 20.57%，差距
`+38.40 pp`，95% CI `[+31.19, +45.51] pp`；桥接成分并集差距为
`+37.08 pp`，结论保持稳定。

- 四个本地 Qwen 模型与一个 OpenAI 兼容 API 模型的统一推理入口

  且差值 95% CI 下界大于 0
