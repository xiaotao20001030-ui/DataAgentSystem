# BIRD Mini-Dev 数据库模式扰动验证性实验报告

**报告版本：** 最新实验结果（2026-10-26）  
**数据集：** BIRD Mini-Dev，500 条问题，11 个数据库  
**模型：** Qwen3 0.6B / 1.7B / 4B，Qwen2.5-Coder 1.5B，DeepSeek API 对照  
**实验规模：** 5,097 个问题变体；question-only 向量检索；SQLite 执行评分

## 摘要

本实验在 BIRD Mini-Dev 的 500 条问题上构造两类模式扰动：加入无关列（随机列、同名/近义列），以及删除多表问题的桥接表或外键列。结果显示：k=10 时外键/关键连接列漏选率为 57.85%，比单表目标列 28.71% 高 29.14 个百分点（95% CI [+21.49,+36.84]）；桥接表内列高 12.89 个百分点。检索假设成立。

执行侧门槛未通过。add_random_20 下四个本地模型相对 API 的准确率下降差为 −1.8、−1.2、+0.6、−3.8 pp；add_synonym_20 下为 −32.0、−25.4、−9.0、−28.2 pp，均未达到“至少高 10 pp”。API 在近义列干扰下下降 41.2 pp，反而比本地模型下降更多。

## 实验设计

- 原始问题 500 条：86 条单表，414 条多表，其中 396 条为有连接关系的多表问题。
- 变体：base 500；random 5/10/20/50 共 2,000；synonym 5/10/20/50 共 2,000；missing_bridge_table 103；missing_fk_column 494；总计 5,097。
- 检索：all-MiniLM-L6-v2，question-only，top-k=5/10/20/50，bootstrap 10,000 次。
- 执行：本地模型贪心解码，DeepSeek Chat 对照；SQLite 执行，30 秒超时。

## 检索结果（漏选率）

| 指标 | k=5 | k=10 | k=20 | k=50 |
|---|---:|---:|---:|---:|
| 单表目标列 | 41.63% | 28.71% | 17.22% | 8.61% |
| 桥接表（表级） | 38.83% | 16.50% | 1.94% | 0.00% |
| 桥接表内列 | 67.60% | 41.60% | 22.80% | 6.00% |
| 外键/关键连接列 | 74.77% | 57.85% | 39.69% | 17.13% |
| 桥接成分并集 | 73.93% | 56.88% | 38.95% | 16.57% |

主分析 k=10：桥接表内列相对单表目标列 +12.89 pp（95% CI [+2.21,+23.45]，p=0.0100）；外键列 +29.14 pp（95% CI [+21.49,+36.84]，p=0.0001）；并集 +28.17 pp（95% CI [+20.58,+35.65]，p=0.0001）。

## 最终结论与局限

本轮实验完成且可复现。RQ1（连接成分漏检）成立，RQ2（小模型在 20 列扰动下比 API 多掉 10 pp）不成立。下一步重点是结构感知 schema 检索、外键增强召回，以及把列名语义歧义和 schema 结构缺失拆开做交叉实验。当前结论基于单一数据集、单一 embedding 和一次贪心推理，尚未证明跨数据集普适性。
