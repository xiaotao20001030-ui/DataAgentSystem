### API 对照判定

API 基线准确率为 68.60%，随机 +20 列为 62.20%，下降 6.40 pp；同名/近义 +20 列为 27.40%，下降 41.20 pp。与 API 对照的配对差值判定见 `model_eval/execution_gate.json`：

- Qwen3 0.6B：随机 +20 相对差值 +0.6 pp；近义 +20 相对差值 -9.0 pp。
- Qwen3 1.7B：随机 +20 相对差值 +0.6 pp；近义 +20 相对差值 -9.0 pp。
- Qwen3 4B：随机 +20 相对差值 +0.6 pp；近义 +20 相对差值 -9.0 pp。
- Qwen2.5-Coder 1.5B：随机 +20 相对差值 -3.8 pp；近义 +20 相对差值 -28.2 pp。

因此“随机增加 20 列时小模型比 API 大模型多下降至少 10 pp”的标准未通过；近义列扰动下 API 大模型下降反而更大。

移除 schema 的执行准确率整体很低。额外 authorizer 诊断发现不少预测 SQL 无法被 SQLite `EXPLAIN`，因此“是否读取被移除项”的合规率存在不可判定记录；见 `analysis/missing_compliance/missing_compliance_audit.md`，不把合规率误报为最终主结论。
