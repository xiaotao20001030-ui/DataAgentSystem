# BGE 对照与外键一跳扩展实验

使用 BIRD Mini-Dev 前 500 题，其中 391 题具有桥接表列或关键连接列标签，共 1,032 个待召回列。检索文档与原实验一致；MiniLM 不加查询指令，BGE 使用其推荐的英文检索查询前缀。对 top-k 命中的列，沿数据库声明的外键补入另一端列，仅补一跳。

| 模型（k=10）         | 普通检索漏选率 |  外键一跳后 |                             下降 | 平均 schema token 数（前→后） |
| ---------------- | ------: | -----: | -----------------------------: | ---------------------: |
| all-MiniLM-L6-v2 |  56.88% | 37.79% | 19.09 pp，95% CI [16.89, 21.28] |            107.6→128.5 |
| BGE base en v1.5 |  61.05% | 37.02% | 24.03 pp，95% CI [21.78, 26.26] |            110.4→127.6 |

置信区间通过按题目重采样 10,000 次得到。MiniLM 的普通 top-10 结果复现原实验 56.88%。BGE 的普通检索在本任务中比 MiniLM 漏选更多，但一跳扩展后的两者结果接近；因此外键结构带来的改善并非 MiniLM 独有。

token 数使用本地 Qwen3-0.6B tokenizer 对所选列的 schema 文本计数，不含问题、证据、系统提示、表之间的额外说明及 SQL 生成输出。外键扩展增加了输入长度，上述结果说明召回与长度的取舍，不代表相同 token 预算下的严格优劣。尚未重跑下游 SQL 执行准确率。
