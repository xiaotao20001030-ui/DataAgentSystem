## 预先固定的判定

随机或近义任一条件下，至少 2/4 小模型相对 API 多掉超过 10 pp，且按题配对 bootstrap 95% 区间下限大于 0，则通过。

**结果：不通过。**

原生 gold SQL 与结果匹配银标签的分层值见 `paired_accuracy.csv`。银标签由 DeepSeek API 产生，可能偏向该 API；分层结果不可省略。

所有模型使用相同 schema 提示和 temperature=0；近义列在 SQLite 副本中真实存在且有同类型来源值。
