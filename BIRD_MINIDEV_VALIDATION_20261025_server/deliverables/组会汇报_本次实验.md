# 7–8 周组会汇报：BIRD Mini-Dev 验证性实验

## Slide 1｜问题

- schema 中加入无关列，或隐藏多表桥接表/连接列，会不会暴露小模型的脆弱性？
- 检索侧关注桥接成分漏选，执行侧关注准确率下降。

## Slide 2｜实验设计

- BIRD Mini-Dev 500 题、11 个数据库、5097 个 schema 变体。
- 随机列与同名/近义列：5/10/20/50；另有缺桥接表、缺外键列。
- Qwen3 0.6B/1.7B/4B、Qwen2.5-Coder 1.5B、DeepSeek API 对照。

## Slide 3｜检索曲线

- top-10 漏选：单表目标列 28.71%。
- 桥接表内列 41.60%；外键/连接列 57.85%；并集 56.88%。
- 外键列比单表目标列高 29.14 pp，检索侧假设成立。

## Slide 4｜执行曲线

- API：基线 68.60%，随机 +20 为 62.20%，近义 +20 为 27.40%。
- Qwen3 0.6B：14.60%→10.00%（随机），14.60%→5.40%（近义）。
- Qwen3 4B：50.60%→43.60%（随机），50.60%→18.40%（近义）。

## Slide 5｜判定

- 随机 +20 的小模型相对 API 下降差：-3.8 到 +0.6 pp。
- 近义 +20：-32.0 到 -9.0 pp。
- “小模型额外下降至少 10 pp”未通过；近义列下 API 下降更多。

## Slide 6｜结论与下一步

- 结论：桥接 schema 的检索漏选是真实现象，预设执行 gate 未成立。
- 结果、曲线、原始 scores 和与旧结果的差异已归档在本文件夹。
