# BIRD Mini-Dev 验证性实验：两页小报告

## 1. 实验设置

在 BIRD Mini-Dev 500 题上，围绕 gold SQL 所需 schema 生成四类条件：基线；随机无关列 5/10/20/50；同名或近义列 5/10/20/50；多表题移除桥接表或外键/连接列。共生成 5097 个变体。评估 Qwen3 0.6B、1.7B、4B、Qwen2.5-Coder 1.5B，并用 DeepSeek `deepseek-chat` 作 API 对照。向量检索使用 all-MiniLM-L6-v2，主指标为 top-10 漏选率。

## 2. 检索结果

question-only top-10 漏选率：单表目标列 28.71%，桥接表内列 41.60%，外键/关键连接列 57.85%，桥接成分并集 56.88%。外键列相对单表目标列高 29.14 个百分点，95% CI 为 [+21.49, +36.84]；桥接表内列高 12.89 个百分点，95% CI 为 [+2.21, +23.45]。桥接相关列的漏选显著更高，检索侧假设成立。

## 3. 执行结果

API 基线准确率 68.60%，随机 +20 列为 62.20%，下降 6.40 pp；同名/近义 +20 列为 27.40%，下降 41.20 pp。Qwen3 0.6B 的对应准确率为 14.60%→10.00% 和 14.60%→5.40%；Qwen3 1.7B 为 27.00%→21.80% 和 27.00%→11.20%；Qwen3 4B 为 50.60%→43.60% 和 50.60%→18.40%；Qwen2.5-Coder 1.5B 为 26.80%→24.20% 和 26.80%→13.80%。

## 4. 判定与限制

“小模型在 +20 列时比 API 大模型多下降至少 10 pp”没有通过：随机 +20 的相对下降差在 -3.8 到 +0.6 pp；近义 +20 的相对下降差在 -32.0 到 -9.0 pp，说明 API 大模型在近义列扰动下反而下降更多。缺外键/连接列时本地模型准确率也明显降低。评分中有 6 个 gold SQL 在统一 30 秒限制内不可评分，summary 按可评分题报告；配对 gate 保留 500 题口径，详情见 `model_eval/execution_gate.json`。

## 5. 结论

结果支持“桥接表相关列更容易在向量检索中漏选”，但不支持预设的“小模型对无关 schema 扰动更脆弱且额外下降至少 10 pp”执行判据。与以前 7-8 周结果相比，主检索结论完全一致，模型 gate 的数值变化不超过约 1.6 pp，方向一致。
